This is the official Leadwerks Lua extension for Visual Code, based in part on [lua-debug by Devcat](https://marketplace.visualstudio.com/items?itemName=devCAT.lua-debug).

You can use the Lua Debugger extension to debug Leadwerks Lua projects with Visual Studio Code.

To enable debugging, enable the **Allow Breakpoints Everywhere** option in Visual Studio Code's settings, found in **User > Features > Debug settings**.

Please see the [Leadwerks documentation](https://www.leadwerks.com/learn) for more information.
